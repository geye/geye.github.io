# 09-账号安全与基础设置
[[README.md|返回总目录]]

打开路径：右上角头像 → Settings

## 菜单翻译
- Account：账号基础信息（昵称、公开邮箱）
- Emails：邮箱配置，建议开启 `Keep my email addresses private` 隐藏真实邮箱
- Notifications：全局消息通知设置
- Access tokens：访问令牌 [[08-Git设置与本地协同]]
- SSH and GPG keys：SSH密钥管理
- Security：安全中心
  - Two-factor authentication (2FA)：双因素认证【强烈建议开启，保护账号】
- Billing and plans：套餐与付费（免费版足够日常开发）

## 重要安全提示
1. 不要把Token、SSH私钥上传到代码仓库！
2. 仓库密钥统一放在：仓库Settings → Secrets and variables → Actions
3. 开启两步验证，防止账号被盗、仓库被篡改。
