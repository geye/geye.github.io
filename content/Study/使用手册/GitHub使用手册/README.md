1. 针对原版GitHub英文界面，**全部菜单附带中文翻译**，解决英文阅读障碍
2. 图文导向操作步骤，重点功能附带实操案例（包含Quartz站点自动部署案例）
3. Markdown格式，同时支持两种场景：

4. 配套你现有项目：Actions预览部署、Dependabot、Pages部署完整讲解
