## 一、Obsidian 简介

Obsidian 是一款基于本地 Markdown 文件的知识管理软件，核心特点：

- **纯本地文件**：所有笔记都是 `.md` 纯文本，不依赖云端，数据完全自己掌控
- **双向链接**：通过 `[[双链]]` 建立笔记之间的关联，形成个人知识网络
- **高度可扩展**：丰富的社区插件，满足从简单记笔记到复杂知识管理的需求
- **所见即所得**：实时预览模式（Live Preview）兼顾源码编辑与阅读体验

## 二、基础界面与核心概念

### 2.1 主要界面区域

| 区域 | 位置 | 功能 |
|------|------|------|
| 文件列表 | 左侧边栏 | 浏览所有笔记文件夹 |
| 搜索 | 左侧边栏 | 全文搜索笔记内容 |
| 编辑区 | 中间主区域 | 撰写和阅读笔记 |
| 反向链接 | 右侧边栏 | 查看哪些笔记链接了当前笔记 |
| 大纲 | 右侧边栏 | 当前笔记的标题结构导航 |
| 标签 | 右侧边栏 | 所有标签汇总 |
| 图谱视图 | 功能按钮 | 可视化笔记关联网络 |

### 2.2 核心概念

- **库（Vault）**：一个文件夹就是一个库，包含所有笔记和配置
- **笔记（Note）**：一篇 `.md` 文件就是一篇笔记
- **双链（WikiLink）**：`[[笔记名]]` 格式的内部链接，Obsidian 核心功能
- **反向链接（Backlink）**：哪些笔记链接了当前这篇笔记
- **锚点（Anchor）**：笔记内的标题或块，用于精确定位跳转

## 三、Markdown 格式语法大全

### 3.1 标题

Obsidian 支持 6 级标题，由 `#` 的数量决定层级。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

> ⚠️ **重要：`#` 后面必须加空格！**
> - ✅ `# 标题` → 正常标题
> - ❌ `#标题` → 会被识别为标签，不是标题

**封闭 ATX 写法（可选）：**
```markdown
# 一级标题 #
## 二级标题 ##
```
行尾的 `#` 仅作装饰，不影响标题等级，渲染效果与普通写法完全一致。不推荐日常使用。

---

### 3.2 文本格式

| 效果 | 语法 | 说明 |
|------|------|------|
| **粗体** | `**粗体文字**` | 推荐使用 `**` |
| *斜体* | `*斜体文字*` | 推荐使用 `*` |
| ***粗斜体*** | `***粗斜体文字***` | 三个星号 |
| ~~删除线~~ | `~~删除线文字~~` | 两个波浪号 |
| ==高亮== | `==高亮文字==` | Obsidian 原生支持 |
| `行内代码` | `` `行内代码` `` | 反引号 |

> 💡 **建议统一使用 `*` 而非 `_`**，避免与文件名、变量名冲突。

---

### 3.3 列表

#### 3.3.1 无序列表

```markdown
- 项目一
- 项目二
  - 子项目（缩进一级）
    - 孙子项目（缩进二级）
```

- `-`、`*`、`+` 三种符号效果完全相同，**推荐统一使用 `-`**
- 每级缩进 **4 个空格** 或 **1 个 Tab**
- 理论上支持无限层级，建议不超过 4 级以保证可读性

#### 3.3.2 有序列表

```markdown
1. 第一步
2. 第二步
3. 第三步
   1. 子步骤一
   2. 子步骤二
```

#### 3.3.3 任务清单（待办列表）

Obsidian 高频功能，点击方框可切换完成状态：

```markdown
- [ ] 未完成任务
- [x] 已完成任务
- [ ] 任务A
  - [ ] 子任务A1
  - [x] 子任务A2
```

#### 3.3.4 列表内换行（重要！）

列表项内多行内容，使用 **`Shift + Enter` 软换行**，文字不会额外缩进：

```markdown
- 列表项标题
  第二行文字（同属一个列表项，不会缩进错位）
  第三行文字
```

> ❌ 错误示范：直接回车会创建新列表项或产生缩进问题

---

### 3.4 引用块

```markdown
> 一级引用文字
>> 嵌套二级引用
>>> 三级引用
```

效果：
> 一级引用文字
>> 嵌套二级引用

### 3.5 代码

#### 3.5.1 行内代码

```markdown
使用命令 `pip install` 安装包
```

效果：使用命令 `pip install` 安装包

#### 3.5.2 多行代码块

使用三个反引号包裹，可指定语言开启语法高亮：

````markdown
```python
def hello():
    print("Hello, Obsidian!")
```
````

常用语言标签：`python`、`javascript`、`bash`、`html`、`css`、`json`、`yaml`、`sql`

#### 3.5.3 嵌套代码（反引号内显示反引号）

使用外层双反引号包裹内层单反引号：

```markdown
`` 这里有一个 `反引号` 符号 ``
```

### 3.6 链接

#### 3.6.1 标准 Markdown 链接

```markdown
[显示文字](https://www.example.com)
```

#### 3.6.2 自动链接

直接粘贴 URL，Obsidian 会自动识别为链接：

```markdown

```

#### 3.6.3 内部链接（双链）

详见 [第四章](#四obsidian-核心功能--双链-wikilink)，这是 Obsidian 最重要的功能。

### 3.7 图片

#### 3.7.1 标准 Markdown 图片

```markdown
![图片描述](图片路径或URL)
```

#### 3.7.2 Obsidian 嵌入图片（推荐）

```markdown
![[image.jpg]]
```

图片放在库内的附件文件夹中，直接用双链语法嵌入，更方便管理。

#### 3.7.3 调整图片大小

```markdown
![[image.jpg|300]]          <!-- 宽度300px -->
![[image.jpg|300x200]]      <!-- 宽300px，高200px -->
```

### 3.8 表格

```markdown
| 姓名 | 年龄 | 职业 |
|------|------|------|
| 张三 | 25   | 工程师 |
| 李四 | 30   | 设计师 |
```

对齐方式：

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 内容   |   内容   |   内容 |
```

### 3.9 分割线

单独一行，三个及以上 `-`、`*` 或 `_`：

```markdown
---
***
___
```

> 💡 推荐使用 `---`，与 YAML Frontmatter 分隔符保持一致风格。

### 3.10 脚注

```markdown
这是一段有脚注的文字[^1]。

[^1]: 这是脚注的具体说明内容。
```

### 3.11 转义符号

如果想让符号原样显示，不被解析为格式，在前面加反斜杠 `\`：

```markdown
\*这不是斜体\*
\#这不是标题
\[\[这不是双链\]\]
```

常用转义：`\*`、`\#`、`\-`、`` \` ``、`\\`、`\[`、`\]`

## 四、Obsidian 核心功能 — 双链 WikiLink

双链是 Obsidian 的灵魂，也是它区别于其他 Markdown 编辑器的核心功能。

### 4.1 双链基础语法

#### 4.1.1 链接到其他笔记

```markdown
[[笔记名称]]
```

- 输入 `[[` 后 Obsidian 会自动弹出笔记搜索框
- 支持模糊搜索，输入关键词快速定位
- 点击可直接跳转到目标笔记
- 目标笔记不存在时，点击会创建新笔记

#### 4.1.2 链接到当前笔记内的标题（锚点）

```markdown
[[#标题文字]]
```

> ⚠️ **必须加 `#`！** 不加 `#` 会被识别为「找一篇同名笔记」，找不到就弹出空白新建窗口。

| 写法 | 含义 | 效果 |
|------|------|------|
| `[[标题]]` | 查找**同名独立笔记文件** | 找不到 → 弹出空白新建 |
| `[[#标题]]` | 跳转到**当前笔记内部标题** | 页面滚动定位 |

#### 4.1.3 链接到其他笔记的指定标题

```markdown
[[笔记名称#标题文字]]
```

---

### 4.2 锚点跳转（标题/块）

#### 4.2.1 标题锚点

```markdown
[[笔记名#一级标题]]
[[笔记名#二级标题]]
[[#当前笔记的某个标题]]
```

> 💡 标题文字必须**完全一致**，包括空格、emoji、标点符号，差一个字符都匹配失败。

#### 4.2.2 块锚点（Block Anchor）

给任意段落添加块 ID，实现精确到段落的跳转：

```markdown
这是一段重要的文字 ^important-block
```

引用方式：

```markdown
[[笔记名#^important-block]]
```

- `^` 前面必须有一个空格
- 块 ID 可以自定义，建议使用有意义的英文标识
- 适用于引用某个具体观点、数据、定义等

---

### 4.3 别名与显示文字

默认情况下，双链显示的就是笔记/标题名称。如需自定义显示文字，使用 `|` 分隔：

```markdown
[[笔记名称|显示的文字]]
[[#标题|显示的文字]]
[[笔记名#标题|显示的文字]]
```

**示例：**
```markdown
详见 [[Quartz部署指南|这篇教程]] 的详细说明。
```
显示效果：详见「这篇教程」的详细说明，点击跳转到 Quartz部署指南 笔记。

---

### 4.4 反向链接与图谱

#### 4.4.1 反向链接（Backlinks）

右侧边栏的「反向链接」面板会显示：
- **链接到当前笔记**的所有笔记列表
- 每篇笔记中具体哪句话引用了当前笔记
- 点击可直接跳转到对应位置

> 💡 反向链接是 Obsidian 知识网络的核心体现，让你发现笔记之间的意外关联。

#### 4.4.2 图谱视图（Graph View）

- 可视化展示所有笔记的关联网络
- 每个节点 = 一篇笔记
- 每条连线 = 一条双链引用
- 可以按标签、文件夹筛选
- 可以调整力导向、颜色、大小等

#### 4.4.3 本地图谱（Local Graph）

当前笔记的关联图谱，只显示与当前笔记直接或间接相连的笔记，适合聚焦某个主题。

---

### 4.5 双链 vs 标准Markdown链接

| 对比项 | `[[双链]]` WikiLink | `[文字](路径)` 标准链接 |
|--------|---------------------|------------------------|
| 语法归属 | Obsidian 扩展语法 | CommonMark 标准语法 |
| 兼容性 | 仅 Obsidian 完整识别 | 所有 Markdown 工具通用 |
| 反向链接 | ✅ 自动生成 | ❌ 不识别 |
| 图谱 | ✅ 显示关联 | ❌ 不显示 |
| 文件改名 | ✅ 自动更新所有链接 | ❌ 链接直接失效 |
| 空格处理 | 直接写空格 | 需转义为 `%20` |
| Quartz 发布 | ✅ 兼容支持 | ✅ 原生完美支持 |
| 书写便捷 | 极高（自动补全） | 较低（手动写路径） |

**使用建议：**
- **纯本地使用**：优先用双链，便捷、自动维护
- **需要发布 Quartz**：两种都可以，跨笔记复杂链接建议标准链接更稳妥
- **不要混合乱用**：同一库内保持统一风格，便于维护

---

### 4.6 双链常见问题

#### Q：点击双链弹出空白文件？
**原因**：`[[名称]]` 没有加 `#`，Obsidian 以为你要找一篇同名笔记，找不到就新建空白。
**解决**：如果是跳转到当前笔记内标题，必须加 `#` → `[[#标题]]`

#### Q：双链跳转找不到标题？
**原因**：标题文字不完全匹配（空格、emoji、标点有差异）
**解决**：确保标题文字与双链中的文字完全一致，建议直接从标题复制

#### Q：双链在其他软件打不开？
**原因**：双链是 Obsidian 专属语法，VSCode、Typora 等不识别
**解决**：需要跨软件使用时，转换为标准 Markdown 链接格式
**插件推荐**：Link Converter 可一键批量转换

#### Q：重命名笔记后双链会断吗？
**不会**。Obsidian 会自动更新库中所有指向该笔记的双链，这是双链的一大优势。

## 五、Obsidian 核心功能 — 大纲与折叠

### 5.1 大纲面板使用

#### 5.1.1 打开大纲面板

右侧边栏 → 点击「大纲」图标（类似三条横线的图标）

#### 5.1.2 大纲的作用

- 自动根据 `#` 标题层级生成结构化目录
- 点击任意标题快速跳转到对应位置
- 拖拽标题可调整顺序（部分主题支持）
- 长文档快速导航的最佳工具

#### 5.1.3 大纲层级规则

完全由标题层级决定，与正文内容无关：

```markdown
# 一级标题 → 大纲第1层
## 二级标题 → 大纲第2层
### 三级标题 → 大纲第3层
```

> 💡 养成良好的标题层级习惯，大纲会自动变得清晰好用。

---

### 5.2 标题折叠与展开

#### 5.2.1 开启折叠功能

设置 → 编辑器 → 打开 **「折叠标题」（Fold headings）**

关闭此选项后，标题左侧不会出现折叠箭头。

#### 5.2.2 折叠/展开操作方式

**方法一：鼠标点击（最常用）**
- 将鼠标移到标题行**最左侧**
- 会出现 ▶（折叠状态）或 ▼（展开状态）箭头
- 点击箭头切换折叠/展开

**方法二：命令面板**
- `Ctrl/Cmd + P` 打开命令面板
- 输入「折叠所有标题和列表」→ 全部折叠
- 输入「展开所有标题和列表」→ 全部展开

**方法三：快捷键（需手动设置）**
- 设置 → 快捷键 → 搜索「Fold more」（折叠更多）
- 搜索「Fold less」（展开更多）
- 自行分配喜欢的快捷键（如 `Ctrl+[` 和 `Ctrl+]`）

#### 5.2.3 折叠层级逻辑

```markdown
# 一级标题（折叠它 → 下面所有内容都隐藏）
## 二级标题（折叠它 → 隐藏到下一个二级标题前）
### 三级标题
正文内容
## 另一个二级标题
```

- 折叠某一级标题，会隐藏该标题**直到下一个同级标题**之前的所有内容
- 父标题折叠后，子标题的折叠状态不影响（都被一起隐藏）

#### 5.2.4 重要限制

⚠️ **折叠功能仅在「编辑视图」可用！**
- 实时预览模式（Live Preview）：✅ 支持折叠
- 源码模式（Source Mode）：✅ 支持折叠
- 阅读视图（Reading View）：❌ 不支持折叠

切换视图快捷键：`Ctrl/Cmd + E`

---

### 5.3 列表折叠

#### 5.3.1 开启列表折叠

设置 → 编辑器 → 打开 **「折叠缩进」（Fold indentation）**

#### 5.3.2 使用方式

- 有子项的列表左侧会出现折叠箭头
- 点击箭头折叠/展开子列表
- 适合长列表、大纲式笔记

```markdown
- 父项（可折叠）
  - 子项1
  - 子项2
    - 孙子项
```

---

### 5.4 永久记住折叠状态

#### 5.4.1 原生限制

⚠️ **Obsidian 原生折叠状态不保存在文件中！**
- 关闭笔记再打开 → 全部恢复展开
- 重启软件 → 全部恢复展开
- 换设备同步 → 全部恢复展开

折叠状态仅存在本地缓存，不随文件同步。

#### 5.4.2 解决方案：Creases 插件

社区插件 **Creases** 可以实现：
- 永久记住每篇笔记的折叠状态
- 同步后在其他设备也能恢复折叠布局
- 支持标题折叠和列表折叠

**安装步骤：**
1. 设置 → 社区插件 → 关闭安全模式
2. 浏览 → 搜索「Creases」
3. 安装并启用
4. 打开笔记后折叠状态会自动保存

## 六、Obsidian 进阶功能

### 6.1 嵌入语法 !

在双链前加 `!`，可以把目标内容**直接嵌入**到当前笔记中显示，而不只是链接。

#### 6.1.1 嵌入整篇笔记

```markdown
![[另一篇笔记名称]]
```

另一篇笔记的全部内容会直接显示在当前位置。

#### 6.1.2 嵌入指定标题下的内容

```markdown
![[笔记名#某个标题]]
```

只嵌入该标题及其下属的所有内容。

#### 6.1.3 嵌入指定块

```markdown
![[笔记名#^block-id]]
```

只嵌入指定的一个段落/块。

#### 6.1.4 嵌入图片

```markdown
![[image.jpg]]
![[image.jpg|300]]    <!-- 指定宽度 -->
```

#### 6.1.5 嵌入音频、视频、PDF

Obsidian 支持嵌入多种媒体格式：

```markdown
![[audio.mp3]]
![[video.mp4]]
![[document.pdf]]
```

> 💡 嵌入 vs 链接的区别：
> - `[[笔记]]` → 显示为蓝色链接文字，点击跳转
> - `![[笔记]]` → 直接显示完整内容，像镶嵌进来一样

---

### 6.2 标签系统

#### 6.2.1 标签语法

```markdown
#工作  #学习  #想法/读书  #项目/已完成
```

> ⚠️ **标签 vs 标题的区别（关键！）**
> - `#标签`（# 后无空格）→ 标签
> - `# 标题`（# 后有空格）→ 一级标题
>
> 空格决定一切！

#### 6.2.2 嵌套标签

使用 `/` 创建层级标签：

```markdown
#项目/进行中
#项目/已完成
#读书/科技/人工智能
```

在标签面板中会以树形结构展示。

#### 6.2.3 标签的用途

- 按主题分类笔记（不依赖文件夹）
- 跨文件夹聚合相关内容
- 图谱视图中按标签着色
- 配合 Dataview 插件做高级查询

#### 6.2.4 标签 vs 文件夹 vs 双链

| 方式 | 特点 | 适用场景 |
|------|------|----------|
| 文件夹 | 物理分类，一篇笔记只属于一个文件夹 | 大的分类体系 |
| 标签 | 灵活标记，一篇笔记可打多个标签 | 跨分类的主题聚合 |
| 双链 | 建立笔记之间的具体关联 | 知识网络、引用关系 |

> 💡 最佳实践：文件夹做大分类 + 标签做灵活标记 + 双链做知识关联，三者配合使用。

---

### 6.3 Callout 提示框

Obsidian 原生支持的提示框语法，非常适合教程、笔记重点标注。

#### 6.3.1 基础语法

```markdown
> [!note] 标题
> 提示框内容
> 可以写多行
```

#### 6.3.2 常用类型

| 类型 | 语法 | 颜色/图标 | 适用场景 |
|------|------|-----------|----------|
| 备注 | `> [!note]` | 蓝色 | 普通说明、补充信息 |
| 摘要 | `> [!abstract]` | 绿色 | 内容摘要、总结 |
| 信息 | `> [!info]` | 蓝色 | 重要信息提示 |
| 待办 | `> [!todo]` | 蓝色 | 任务清单 |
| 提示 | `> [!tip]` | 绿色 | 技巧、小窍门 |
| 成功 | `> [!success]` | 绿色 | 成功状态、完成 |
| 问题 | `> [!question]` | 黄色 | 疑问、思考题 |
| 警告 | `> [!warning]` | 黄色 | 注意事项、警告 |
| 失败 | `> [!failure]` | 红色 | 失败、错误 |
| 危险 | `> [!danger]` | 红色 | 危险操作、严重警告 |
| 错误 | `> [!bug]` | 红色 | Bug、问题 |
| 示例 | `> [!example]` | 紫色 | 示例、演示 |
| 引用 | `> [!quote]` | 灰色 | 引用、摘录 |

#### 6.3.3 可折叠 Callout

加 `-` 号实现可折叠：

```markdown
> [!faq]- 常见问题（点击展开）
> 这是折叠起来的答案内容
```

默认展开用 `+`：
```markdown
> [!faq]+ 常见问题（默认展开）
> 这是答案内容
```

### 6.4 元数据 Frontmatter

笔记最顶部的 YAML 元数据区，用 `---` 包裹。

#### 6.4.1 基础语法

```yaml
---
title: 笔记标题
tags: [工作, 项目A]
date: 2026-08-01
status: 进行中
---
```

#### 6.4.2 常用字段

| 字段 | 用途 |
|------|------|
| `tags` | 笔记标签（与正文中的标签等效） |
| `aliases` | 笔记别名，双链中使用别名也能找到 |
| `date` | 创建/修改日期 |
| `status` | 自定义状态 |
| `category` | 分类 |
| `publish` | 是否发布（Quartz 等工具会用到） |

#### 6.4.3 别名 aliases 用法

```yaml
---
aliases:
  - 简称
  - 另一个名字
---
```

设置别名后，输入 `[[简称]]` 也能链接到这篇笔记。

### 6.5 模板功能

#### 6.5.1 启用核心插件

设置 → 核心插件 → 打开「模板」（Templates）

#### 6.5.2 设置模板文件夹

1. 新建一个文件夹，如 `00-模板`
2. 设置 → 模板 → 模板文件夹位置 → 选择该文件夹

## 七、目录与导航最佳实践

### 7.1 手动目录写法

#### 7.1.1 同笔记内部目录（推荐双链）

```markdown
## 目录

- [[#一、简介]]
- [[#二、安装步骤]]
  - [[#2.1 下载]]
  - [[#2.2 安装]]
- [[#三、使用方法]]
```

> ✅ 优点：自动维护，标题改名后链接自动更新，跳转准确

#### 7.1.2 跨笔记目录（MOC 方式）

```markdown
# 项目总览

## 技术文档
- [[前端开发指南]]
- [[后端API文档]]
- [[数据库设计]]

## 会议记录
- [[2026-08-01 项目启动会]]
- [[2026-08-15 需求评审会]]
```

> MOC（Map of Content）是 Obsidian 经典的内容组织方式，用一篇笔记作为索引目录。

---

### 7.2 目录缩进规范

#### 7.2.1 缩进层级建议

| 层级 | 用途 | 示例 |
|------|------|------|
| 第1级 | 大章节 | 一、二、三 |
| 第2级 | 小节 | 1.1、2.1 |
| 第3级 | 子小节 | 2.1.1 |
| 第4级 | 细分点 | 2.1.1.1 |

> 💡 **建议不超过 4 级**，太深会导致页面缩进严重，阅读体验差。

#### 7.2.2 标准缩进写法

每级缩进 **4 个空格**：

```markdown
- [[#一、Quartz 静态站点搭建]]
    - [[#1.1 环境准备]]
    - [[#1.2 下载并初始化 Quartz]]
- [[#二、Nginx 部署静态站点]]
    - [[#2.1 🐧Linux版安装]]
        - [[#2.1.1 下载与安装]]
        - [[#2.1.2 静态站点配置]]
            - [[#2.1.2.1 站点创建]]
    - [[#2.2 Windows版安装]]
```

#### 7.2.3 避坑提醒

- ❌ 不要混用 Tab 和空格缩进
- ❌ 不要一级缩 2 格、下一级缩 4 格，保持一致
- ✅ 统一用 4 个空格或统一用 1 个 Tab

---

### 7.3 命名规范建议

#### 7.3.1 笔记命名

- 使用有意义的中文或英文名称
- 避免特殊字符（`/`、`\`、`:` 等会导致文件问题）
- 可加日期前缀：`2026-08-01 会议记录`
- 系列笔记可用前缀：`项目-需求文档`、`项目-技术方案`

#### 7.3.2 标题命名

- 层级清晰，不要跳级（不要从 `#` 直接跳到 `###`）
- 同一篇笔记内标题不要重名
- 标题简洁明了，不超过 20 个字为宜

## 八、常见问题与避坑指南

### 8.1 格式类

**Q：`#标题` 为什么不是标题？**
A：`#` 后面必须加空格才是标题，`#标题` 会被识别为标签。

**Q：列表内换行文字缩进错位怎么办？**
A：使用 `Shift + Enter` 软换行，或把多行内容放在同一个列表项里。

**Q：反引号里面怎么显示反引号？**
A：外层用双反引号包裹：`` `这里有一个`反引号`符号` ``

### 8.2 双链类

**Q：点击双链弹出空白文件？**
A：没加 `#` 导致的。跳当前笔记内标题必须写 `[[#标题]]`。

**Q：双链跳转不到标题？**
A：检查标题文字是否完全一致，包括空格、emoji、标点。

**Q：双链在 VSCode 里不生效？**
A：双链是 Obsidian 专属语法，其他编辑器不识别。需要通用格式请用标准 Markdown 链接。

### 8.3 折叠类

**Q：标题旁边没有折叠箭头？**
A：设置 → 编辑器 → 确认「折叠标题」已开启；确认当前是编辑视图不是阅读视图。

**Q：关闭笔记再打开折叠状态没了？**
A：原生正常现象，折叠状态不保存到文件。需要永久保存请安装 Creases 插件。

### 8.4 其他

**Q：Obsidian 同步收费吗？**
A：官方同步服务收费，但你可以用 Git、iCloud、OneDrive、坚果云等第三方方式免费同步。

**Q：笔记会丢失吗？**
A：Obsidian 操作的是本地文件，只要不手动删除、硬盘不坏，就不会丢。建议定期备份或用 Git 版本控制。

## 九、Obsidian + Quartz 发布规范

### 9.1 格式兼容性

| 语法 | Obsidian | Quartz | 备注 |
|------|----------|--------|------|
| 标准 Markdown | ✅ | ✅ | 完全兼容 |
| 双链 `[[ ]]` | ✅ | ✅ | Quartz 做了兼容 |
| 嵌入 `![[ ]]` | ✅ | ✅ | 大部分支持 |
| Callout `> [!note]` | ✅ | ✅ | Quartz 原生支持 |
| 高亮 `== ==` | ✅ | ✅ | 支持 |
| Dataview | ✅ | ⚠️ | 需要额外配置 |
| 任务列表 `- [ ]` | ✅ | ✅ | 支持 |

### 9.2 发布建议

1. **链接格式**：内部链接两种都可以，跨库复杂链接建议用标准 Markdown 更稳妥
2. **图片管理**：统一放在 `attachments` 或 `assets` 文件夹，用相对路径引用
3. **Frontmatter**：善用 `publish: true/false` 控制哪些笔记发布
4. **标签**：发布前检查标签是否符合网站分类体系
5. **测试预览**：发布前本地 `npx quartz build` 预览效果

### 9.3 推荐目录结构

```
你的库/
├── 00-模板/           # 模板文件
├── 01-笔记/           # 日常笔记
├── 02-项目/           # 项目笔记
├── 03-知识/           # 知识卡片
├── 04-发布/           # 准备发布到 Quartz 的内容
├── attachments/       # 图片等附件
└── 索引笔记.md        # MOC 总目录
```
