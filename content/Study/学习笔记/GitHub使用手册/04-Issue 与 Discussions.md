## 1. Issue 工单系统
菜单路径：仓库 → Issues → New issue
翻译：新建工单
适用场景：BUG反馈、功能需求、任务清单

界面字段翻译：
- Title：标题，简明描述问题
- Write：编辑内容，支持Markdown
- Preview：预览效果
- Assignees：负责人，指派人员处理这个工单
- Labels：标签（bug/feature/question 分类）
- Milestone：版本里程碑
- Projects：关联项目看板

常用操作：
Close issue：关闭工单（问题处理完成）
Reopen issue：重新打开已关闭工单

## 2. Discussions 社区讨论
菜单：仓库 → Discussions
区别 Issue：
Issue = 正式任务、bug；Discussions = 自由交流、提问、想法讨论

分类：
- Announcements：官方公告
- General：通用交流
- Q&A：问答板块
