# 📝 02. 基础语法规则

> [!info] 本章概述
> 学习 Python 的基本语法规则，包括缩进、注释、命名规范等。
> 预计学习时间：40 分钟

> [!warning] 重点提醒
> **缩进是 Python 最重要的语法规则**，一定要掌握！

---

## 2.1 缩进（最重要！）

Python **用缩进区分代码块**，而不是大括号 `{}`。

### 基本规则

- 推荐用 **4 个空格** 缩进（官方标准）
- 同一层级代码必须对齐
- 缩进错误会直接报错 `IndentationError`

### 示例

```python
# ✅ 正确
if True:
    print("第一行")
    print("第二行")

# ❌ 错误（缩进不一致）
if True:
    print("第一行")
      print("第二行")  # 报错！IndentationError
```

> [!caution] 常见错误
> - 不要混用 Tab 和空格
> - 同一代码块的缩进必须一致
> - 不要忘记缩进（if/for/while/def/class 后面的代码块都要缩进）

## 2.2 注释

### 单行注释

用 `#` 开头，`#` 后面的内容都会被忽略：

```python
# 这是单行注释
print("hello")  # 也可以写在代码后面
```

### 多行注释（文档字符串）

用三个引号（单引号或双引号都可以）：

```python
"""
这是多行注释
也叫文档字符串 docstring
通常用在函数、类、模块开头说明用途
"""

'''
也可以用三个单引号
效果一样
'''
```

> [!tip] 注释的最佳实践
> - 代码本身说明「做什么」，注释说明「为什么」
> - 不要写废话注释（如 `a = 1  # 把1赋值给a`）
> - 复杂逻辑一定要加注释

## 2.3 语句换行

### 一行一条语句（推荐）

```python
print("hello")
print("world")
```

### 一行多条语句（不推荐）

用分号分隔：

```python
print("a"); print("b")  # 不推荐，可读性差
```

### 一条语句多行

**方式 1：用反斜杠 `\`**
```python
total = 1 + 2 + 3 + \
        4 + 5
```

**方式 2：用括号自动换行（推荐）**
```python
total = (1 + 2 + 3 +
         4 + 5)
```

> [!tip] 推荐用括号
> 括号内的代码可以自动换行，不需要反斜杠，更优雅。

## 2.4 标识符命名规则

变量名、函数名、类名等统称为标识符。

### 命名规则

1. 由**字母、数字、下划线**组成
2. **不能以数字开头**
3. 不能是 Python 关键字（保留字）
4. **区分大小写**（`age` 和 `Age` 是两个不同变量）

### 示例

```python
# ✅ 合法命名
name = "Tom"
age_1 = 18
_user = "test"

# ❌ 非法命名
1name = "Tom"    # 数字开头
my-name = "Tom"  # 含减号
$money = 100     # 含特殊符号
```

---

## 2.5 命名规范（约定俗成）

| 类型 | 规范 | 示例 |
|------|------|------|
| 变量/函数名 | 小写 + 下划线（蛇形命名） | `user_name`, `get_info()` |
| 类名 | 大驼峰 | `MyClass`, `PersonInfo` |
| 常量 | 全大写 + 下划线 | `MAX_SIZE`, `DEFAULT_PORT` |
| 模块名 | 小写 + 下划线 | `my_module.py`, `utils.py` |
| 私有变量/方法 | 单下划线开头 | `_private_var`, `_internal_method()` |

> [!note] 说明
> 这些是「约定俗成」的规范，不遵守代码也能运行，但会被认为不专业。

## 2.6 Python 关键字（保留字）

共 35 个关键字，不能用作变量名：

```
False, None, True, and, as, assert, async, await,
break, class, continue, def, del, elif, else, except,
finally, for, from, global, if, import, in, is,
lambda, match, nonlocal, not, or, pass, raise, return,
try, while, with, yield, case
```

### 查看关键字的方法

```python
import keyword

print(keyword.kwlist)       # 列出所有关键字
print(keyword.iskeyword("if"))  # 判断是否为关键字
```

## 2.7 输入与输出

### 输出 print()

```python
# 输出字符串
print("Hello World")

# 输出多个内容，默认用空格分隔
print("我叫", "Tom", "今年", 18, "岁")

# 指定分隔符
print("a", "b", "c", sep="-")  # a-b-c

# 指定结尾符（默认是换行）
print("hello", end=" ")  # 不换行，结尾加空格
print("world")
```

### 输入 input()

```python
# 获取用户输入，返回的是字符串
name = input("请输入你的名字：")
print("你好，" + name)

# 如果需要数字，要类型转换
age = int(input("请输入年龄："))
print("明年你" + str(age + 1) + "岁")
```

> [!warning] 注意
> `input()` 返回的永远是字符串，即使输入的是数字。
> 需要数字时要用 `int()` 或 `float()` 转换。
