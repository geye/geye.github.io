## 1.1 Python 是什么

Python 是一门**高级编程语言**，由 Guido van Rossum 于 1991 年创建。

### 核心特点

- **语法简洁**：接近自然语言，代码可读性强
- **解释型语言**：不需要编译，写完直接运行
- **跨平台**：Windows / Mac / Linux 都能跑
- **动态类型**：变量不需要声明类型
- **开源免费**：社区活跃，生态丰富

### 应用领域

| 领域 | 代表库/框架 |
|------|-----------|
| Web 开发 | Django、Flask、FastAPI |
| 数据分析 | Pandas、NumPy、Matplotlib |
| 人工智能 | TensorFlow、PyTorch、scikit-learn |
| 自动化运维 | Ansible、SaltStack |
| 网络爬虫 | Scrapy、Requests、BeautifulSoup |
| 游戏开发 | Pygame |
| 桌面应用 | PyQt、Tkinter |

## 1.2 安装 Python

### Windows 安装

> [!tip] 安装要点
> 一定要勾选 **Add Python to PATH**，否则命令行找不到 python 命令

1. 官网下载：[python.org/downloads](https://www.python.org/downloads/)
2. 运行安装程序，勾选「Add Python to PATH」
3. 点击「Install Now」默认安装
4. 打开 cmd，输入以下命令验证：

```bash
python --version
# 或
python -V
```

### Mac 安装

**方式 1：官网下载安装包**
- 从 [python.org](https://www.python.org/downloads/) 下载 macOS 版本安装

**方式 2：Homebrew（推荐）**
```bash
brew install python3
```

### Linux 安装

**Ubuntu/Debian：**
```bash
sudo apt update
sudo apt install python3 python3-pip
```

**CentOS/RHEL：**
```bash
sudo yum install python3 python3-pip
```

## 1.3 第一个 Python 程序

### 创建 hello.py

```python
# hello.py
print("Hello, Python!")
print("我正在学习Python")
```

### 运行程序

```bash
python hello.py
```

> [!note] 注意
> - Mac/Linux 上可能需要用 `python3` 而不是 `python`
> - 确保当前目录在 hello.py 所在的文件夹

## 1.4 交互式模式（REPL）

直接在终端输入 `python` 进入交互模式，可以一行一行执行代码：

```python
>>> 1 + 1
2
>>> print("hi")
hi
>>> name = "Python"
>>> name
'Python'
>>> exit()  # 退出交互模式
```

> [!tip] 交互模式的用途
> - 快速测试小段代码
> - 学习和探索新功能
> - 作为计算器使用
