# 第6章 打印和管理打印任务

> 所属：第二部分 使用文件
> 来源：Linux命令速查手册

Linux使用CUPS（Common UNIX Printing System）管理打印。主要命令分为三类：提交打印、查看队列、取消任务。

---

## 6.1 列出所有可用的打印机

```bash
lpstat -p
```

列出系统中所有可用的打印机及其状态。

---

## 6.2 找到默认的打印机

```bash
lpstat -d
```

显示系统默认打印机。

---

## 6.3 查看打印机是如何连接的

```bash
lpstat -s
```

显示打印机状态和连接方式（USB、网络、IPP等）。

---

## 6.4 一次性获取打印机的所有信息

```bash
lpstat -t
```

显示所有打印相关信息：打印机、队列、状态等全部内容。

---

## 6.5 将文件打印到默认的打印机

```bash
lpr filename
lp filename
```

提交打印任务到默认打印机。

- `lpr`：BSD风格
- `lp`：System V风格

两者功能差不多，选一个习惯的用就行。

---

## 6.6 将文件打印到任何打印机

```bash
lpr -P printer_name filename
lp -d printer_name filename
```

指定打印机打印。

- `-P` 用于 lpr
- `-d` 用于 lp

---

## 6.7 打印多份文件

```bash
lpr -# 5 filename
lp -n 5 filename
```

打印指定份数。

---

## 6.8 列出打印任务

```bash
lpq
lpstat -o
```

查看打印队列，显示等待中的打印任务。

---

## 6.9 按打印机来列出打印任务

```bash
lpq -P printer_name
```

查看指定打印机的队列。

---

## 6.10 取消发送到默认打印机上的当前打印任务

```bash
lprm
```

取消当前（自己提交的）打印任务。

---

## 6.11 取消发送到任何打印机上的打印任务

```bash
lprm -P printer_name job_id
cancel job_id
```

指定任务ID取消。

可以先用 `lpq` 或 `lpstat -o` 查看任务ID。

---

## 6.12 取消所有的打印任务

```bash
lprm -
```

取消所有打印任务（需要权限）。

---

## 6.13 小结

### 打印命令速查

| 操作 | lpr 系 | lp 系 |
|------|--------|-------|
| 打印文件 | `lpr file` | `lp file` |
| 指定打印机 | `lpr -P printer` | `lp -d printer` |
| 打印多份 | `lpr -# 5` | `lp -n 5` |
| 查看队列 | `lpq` | `lpstat -o` |
| 取消任务 | `lprm job_id` | `cancel job_id` |
| 取消所有 | `lprm -` | |

### 状态查询

| 命令 | 用途 |
|------|------|
| `lpstat -p` | 列出所有打印机 |
| `lpstat -d` | 显示默认打印机 |
| `lpstat -t` | 显示全部打印信息 |
