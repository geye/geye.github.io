# 卷2 第3章 接口层

## 3.1 引言

接口层提供与硬件无关的编程接口。

### 支持功能
1. 标准接口函数
2. 标准统计与控制标志
3. 协议地址存储
4. 输出分组排队

### 三种示例接口
- **以太网**：广播局域网
- **SLIP**：点对点串行
- **环回**：逻辑网络

## 3.4 ifaddr结构

- 每个接口维护地址列表
- 每个协议一个地址
- 支持多IP地址

### 成员
| 成员 | 说明 |
|------|------|
| ifa_next | 下一个地址 |
| ifa_ifp | 回指接口 |
| ifa_addr | 协议地址 |
| ifa_netmask | 网络掩码 |
| ifa_dstaddr | 点对点目标/广播地址 |

## 3.5 sockaddr结构

通用地址结构：
- sa_len：地址长度
- sa_family：地址族
- sa_data：协议相关数据

### 地址族
| 常量 | 说明 |
|------|------|
| AF_INET | Internet |
| AF_OSI | OSI |
| AF_UNIX | Unix域 |
| AF_LINK | 链路层 |
| AF_ROUTE | 选路 |

## 3.6 ifnet与ifaddr的专用化

- 设备专用结构以ifnet开头
- 协议专用结构以ifaddr开头

## 3.7 网络初始化概述

1. `cpu_startup`：检测硬件设备
2. `main`：调用`pdevinit`数组中的attach函数
3. `ifinit`：接口初始化
4. `domaininit`：协议初始化

## 3.10 环回初始化

- MTU：1536字节
- 设置IFF_LOOPBACK和IFF_MULTICAST

## 3.11 if_attach函数

- 初始化ifnet结构
- 插入接口链表
- 创建链路层地址（sockaddr_dl）

## 3.12 ifinit函数

- 设置输出队列最大长度（50）
- 启动监视定时器

## 3.13 小结

ifnet和ifaddr是接口层的核心数据结构。初始化由系统引导过程完成。
