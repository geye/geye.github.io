# 卷2 第6章 IP编址

## 6.1 引言

本章讨论IP地址管理。

### IP地址要点
- 地址分配给接口，而非系统
- A/B/C类：单播
- D类：多播
- 环回网络：127.0.0.0

## 6.2 代码介绍

- `netinet/in.h`：Internet地址定义
- `netinet/in_var.h`：Internet接口定义
- `netinet/in.c`：初始化
- `netinet/if.c`：接口实用函数

## 6.3 接口和地址小结

每个接口维护链路层地址和IP地址列表。

## 6.4 sockaddr_in结构

```c
struct sockaddr_in {
    u_char sin_len;
    u_char sin_family;
    u_short sin_port;      // 网络字节序
    struct in_addr sin_addr;
    char sin_zero[8];
};
