# 📚 TCP/IP 详解

> 本仓库包含《TCP/IP详解》卷1和卷2的完整整理笔记，采用 Obsidian 格式，支持双链接和知识网络。

## 📖 关于本书

《TCP/IP详解》是互联网协议领域的经典之作，由 W. Richard Stevens 等人撰写。本仓库将卷1（协议）和卷2（实现）的内容整理为结构化的 Markdown 文件，适合使用 Obsidian、Quartz 等工具进行知识管理和阅读。
