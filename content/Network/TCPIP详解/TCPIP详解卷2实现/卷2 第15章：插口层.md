# 卷2 第15章 插口层

## 15.1 引言

插口层将进程请求映射到协议实现。

## 15.2 代码介绍

- `sys/socketvar.h`：socket结构
- `kern/uipc_syscalls.c`：系统调用
- `kern/uipc_socket.c`：插口层函数

## 15.3 socket结构

### 成员
| 成员 | 说明 |
|------|------|
| so_type | 插口类型 |
| so_options | 选项 |
| so_linger | 拖延时间 |
| so_state | 状态 |
| so_pcb | 协议控制块 |
| so_proto | 协议交换结构 |
| so_rcv | 接收缓存 |
| so_snd | 发送缓存 |

### 插口状态
| 标志 | 说明 |
|------|------|
| SS_ASYNC | 异步通知 |
| SS_NBIO | 非阻塞 |
| SS_ISCONNECTED | 已连接 |
| SS_ISCONNECTING | 正在连接 |
| SS_ISDISCONNECTING | 正在断开 |
| SS_CANTRCVMORE | 不能接收 |
| SS_CANTSENDMORE | 不能发送 |

text
proc{} → filedesc{} → file{}[] → file{} → socket{}

tsleep：进程睡眠

## 15.16 小结
