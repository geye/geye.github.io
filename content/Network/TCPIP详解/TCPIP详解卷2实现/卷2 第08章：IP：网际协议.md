## 8.3 IP分组

### 术语
- **报文**：传输协议交给IP的数据
- **数据报**：报文 + IP首部
- **分片**：数据报的分段
- **分组**：链路层传输单元

### ip结构
```c
struct ip {
    u_char ip_v:4;      // 版本
    u_char ip_hl:4;     // 首部长度
    u_char ip_tos;      // 服务类型
    u_short ip_len;     // 总长度
    u_short ip_id;      // 标识
    u_short ip_off;     // 偏移+标志
    u_char ip_ttl;      // 生存时间
    u_char ip_p;        // 协议
    u_short ip_sum;     // 检验和
    struct in_addr ip_src, ip_dst;
};
```
